# Synthetic population for activity-based transport modelling

Code repository for developing and evaluating synthetic populations for activity-based transport modelling in Australia. The project will combine Census-based household and person synthesis with transport-attribute enrichment using household travel surveys.

Initial development focuses on Greater Melbourne, with expansion to Victoria and Australia subject to data coverage and validation. The first study tests whether learning from travel diaries improves the joint generation of driving licences, household bicycles and recent working-from-home patterns.

- [Study concept](docs/study-concept.md): research question, proposed method and evaluation.

Implementation has not started yet; the repository currently contains the study concept. Code for data preparation, population synthesis, evaluation and reproducible experiments will be added as development progresses.

Visual notes and literature materials are maintained locally and excluded from version control.
